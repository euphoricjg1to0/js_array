Recap on Variables

A variable is like a container that stores information in your program.


var pokemon1 = "Pikachu";
var pokemon2 = "Snorlax";
var pokemon3 = "Charizard";

What if you had 1000 Pokémon? Arrays make this easier!

What is an Array?

An array is a special variable that can hold multiple values, accessible by index numbers (starting from 0).


const pokemon = ["Pikachu", "Snorlax", "Charizard"];
